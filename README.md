🛠️ Prerequisites & Dependencies
To run these scripts successfully, ensure you have Python installed along with the required scientific computing libraries. You can install them using pip:

Bash
pip install numpy scipy matplotlib

Required Libraries:
NumPy: For array storage, vectorization, and matrix operations.

SciPy: For advanced numerical solvers, optimization, integration, and interpolation.

Matplotlib: For visualizing simulation results, convergence plots, and graphs.


🚀 Running the Programs
Navigate to the code/ directory and execute any script using Python. For example, to run the NumPy arrays task:

Bash
python code/Task_02_numpy_arrays.py


Task Documentation (A–E): Each task script identifies input parameters, performs mathematical operations, modifies parameters for sensitivity analysis, explains outputs/graphs, and adapts models to real-world scenarios.
